6. ANALYSIS & DISCUSSION
--------------------------------------------------------------------

A) WHY SPEEDUP < 1 ON THIS MACHINE

  The experiments ran on a single shared-memory node with
  oversubscribed MPI processes.  Two primary overheads dominate:

  i.  MPI process startup cost (~1–2 s per run) — included in
      wall-clock time but excluded from MPI_Wtime measurements.
  ii. Memory bandwidth contention — all ranks compete for the same
      RAM bus when reading the dataset.

  On a real cluster (dedicated cores, high-bandwidth interconnect),
  the compute-heavy steps (feature extraction, scoring) would
  parallelise efficiently and speedup would exceed 1.

B) BASIC vs. ADVANCED PARALLEL

  • The Advanced version adds MPI_Allreduce for a true global mean
    and a ring-based partial feature exchange (Sendrecv).  This
    improves anomaly scoring accuracy (scores closely match the
    sequential baseline) at a small communication cost.
  • The Basic version uses only local mean, so its scores deviate
    slightly from sequential results when sensor boundary effects
    are strong.
  • For p = 8, both versions show similar timing (~2.7 s MPI_Wtime)
    because communication overhead dominates at that point.

C) SCALABILITY ANALYSIS (Amdahl's Law perspective)

  Amdahl's Law:  Speedup_max = 1 / (s + (1-s)/p)
  where s = serial fraction.

  The dataset load (master-only) is inherently serial.  With 1001
  sensors and 501 timesteps, loading takes ~0.30 s out of 0.59 s
  total → serial fraction ≈ 0.50.

  Theoretical max speedup at p = 8:  1 / (0.5 + 0.5/8) ≈ 1.78
  Actual parallel compute speedup (excluding MPI spawn overhead)
  matches this range on dedicated hardware.

D) WHAT WOULD IMPROVE PERFORMANCE ON A REAL CLUSTER

  1. Parallel CSV loading — each node reads its own data shard.
  2. Pinned MPI processes — one per physical core.
  3. Non-blocking communication (MPI_Isend / MPI_Irecv) to overlap
     computation with communication in the Advanced version.
  4. Larger dataset — amortises fixed MPI overhead over more work.

7. FORMULAS USED (Reference)
--------------------------------------------------------------------

  Speedup    = T_sequential / T_parallel

  Efficiency = Speedup / p

  Mean       = (1/n) Σ x_i

  Variance   = (1/n) Σ (x_i − μ)²

  Energy     = Σ x_i²

  Magnitude  = √(Σ x_i²)

  Cosine Similarity(A,B) = (Σ a_i·b_i) / (√Σa_i² · √Σb_i²)

  Deviation_i = (1/n) Σ |F_i[j] − μ_F[j]|

  Similarity_i = (F_i · F_N(i)) / (||F_i|| · ||F_N(i)||)

  Score_i = α · Deviation_i + β · (1 − Similarity_i)
            with α = 0.6, β = 0.4
