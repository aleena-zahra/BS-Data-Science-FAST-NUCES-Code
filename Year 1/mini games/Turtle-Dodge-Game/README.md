## <img src="https://media.giphy.com/media/VgCDAzcKvsR6OM0uWg/giphy.gif" width="50"> Introduction

Welcome to the **Turtle Dodge Game**! A fun, fast-paced arcade-style game made using Python’s built-in `turtle` module. You're a red turtle in a forest, dodging falling turtles from above. Stay sharp — if one hits you, it's game over!

## <img src="https://media.giphy.com/media/VbK2YCQFWdg5nvH5wa/giphy.gif" width="30"> Features

- 🐢 **Three-lane enemy spawn**: Enemies fall from the top at random.
- 💥 **Collision detection**: One hit and you're out.
- 🎵 **Background music**: Toggle immersive gameplay music.
- 🌄 **Switchable backgrounds**: Change scenery mid-game with the spacebar.
- 📈 **Scoring system**: Gain points for every dodge.
- 🔁 **Replay-friendly**: Instant restart upon collision.


## <img src="https://media.giphy.com/media/KOLIHpiF4BVzQBUYUt/giphy.gif" width="50"> Game Controls 🎮

| Key       | Action              |
|-----------|---------------------|
| `←`       | Move Left           |
| `→`       | Move Right          |
| `↑`       | Move Up             |
| `↓`       | Move Down           |
| `Spacebar`| Toggle Background   |
